# Search: find a piece and bring it into the library

1. **Check the library.** `ssh gaia "find '/srv/mergerfs/gaia_data/gaia-library/Sheet Music' -iname '*<keyword>*'"` with the composer's surname and a title word. Already there in the wanted instrumentation → show the user the path and stop. Done when you know whether the library has it.
2. **Find the work.** `python3 imslp.py search "<composer> <title>"`, then `python3 imslp.py work "<exact title>"`. Try alternative titles (original language, catalogue number) until the right work page is open. Done when you hold one work page whose instrumentation matches what the user wants.
3. **Choose the edition.** Eligible: status `PD-EU`, `CC` or `PD-dedicated`. `CHECK` means a living or recently dead editor/arranger, or missing dates: take it only if no eligible edition fits, and then ask the user first. Among eligible editions prefer, in order: the right forces (the arrangement section for anything other than the original instrumentation), complete (score **and** every part the user plays from), typeset or a clean scan over grayscale, an Urtext or first edition over a heavily edited one. Pick one edition; take the files the user needs from it (typically score + solo part). Done when every chosen file is named with its link.
4. **Hand over the links.** Give the user the direct links as a short list, one per file, with what each is. IMSLP's CAPTCHA blocks scripted downloads, so the user clicks them; the browser saves to `~/Downloads`. Wait until the user says they're downloaded.
5. **Collect.** Find each file in `~/Downloads` by the link's basename (URL-decoded; browsers sometimes turn `_` into spaces or add ` (1)`). `scp <files> "gaia:/srv/mergerfs/gaia_data/gaia-library/Sheet Music/Inbox/"` (scp's SFTP mode takes the spaced path as is), compare sizes on both ends, then delete the local copies. Done when every chosen file is in the Inbox at full size.
6. **File it**: follow **ingest.md** from step 2 (Lint). You already know each file's identity from the IMSLP page; still open page 1 to confirm.
